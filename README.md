# Sales Orders Dashboard

## Project Overview

The **Sales Orders Dashboard** is an interactive data visualization project developed to analyze sales performance, product distribution, geographical sales trends, and order fulfillment status.

The primary objective of this project is to transform raw sales data into meaningful business insights through data aggregation, analytical visualization, and performance monitoring.

The dashboard provides a consolidated view of sales operations, enabling stakeholders to identify high-performing cities, evaluate product-level performance, and monitor order status distribution.

## Business Objectives

- Analyze sales distribution across different cities.
- Identify top-performing products based on sales volume.
- Monitor order fulfillment status, including Completed, Pending, and Cancelled orders.
- Compare product-level sales performance.
- Present key business metrics through an interactive dashboard.

## Dashboard Features

### 1. Sales by City
- Visualizes the geographical distribution of sales orders.
- Compares sales performance across Bengaluru, Mysuru, Chennai, and Hyderabad.
- Helps identify cities generating higher order volumes.

### 2. Sales by Products
- Represents product-wise sales contribution using a Pie Chart.
- Analyzes the distribution of sales across Laptop, Monitor, Headphones, Mouse, Keyboard, and Webcam.
- Helps identify product demand patterns.

### 3. Order Status by City
- Displays order fulfillment status using a horizontal bar chart.
- Compares Completed, Pending, and Cancelled orders.
- Provides visibility into order processing and fulfillment performance.

### 4. Product-Level Sales Analysis
- Uses a Line Chart to compare sales volume across different products.
- Highlights variations in product-level performance.
- Supports product demand evaluation and inventory-related decisions.

## Key Business Insights

- Bengaluru and Mysuru recorded the highest order volumes among the displayed cities.
- Laptop and Monitor have the highest product-level sales counts in the dashboard.
- Completed orders represent the largest portion of the displayed order statuses.
- Pending and Cancelled orders indicate opportunities to improve order processing and fulfillment efficiency.
